■概要
温度センサーで温度を測定し、測定した温度をLCDに表示する。

■開発の進め方
githubのIssuesを起票し、Issueごとにブランチを作成。
Issueに対応完了した場合、作成したブランチからmasterブランチにIssueを関連づけしたプルリクエストを発行しマージする。

■システム構成、インターフェイス
・温度センサー : ArduinoからOneWire規格通信
・LCD : ArduinoからI2C規格で通信

■ソフトウェアシステムアーキテクチャ設計方針
機能ごとにファイル分割する。
機能ごとに周期タスクで駆動し、mainループから周期タスクを呼び出す。
